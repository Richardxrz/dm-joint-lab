## 一、总线参数（p11）

| 项 | 值 | 出处 |
|---|---|---|
| 帧格式 | CAN **标准帧**（STD，11 位 ID） | p11 |
| 默认波特率 | **1 Mbps** | p11 |
| 反馈方式 | **问询式**：电机收到与其 CAN ID 匹配的帧就回一帧反馈 | p11 |
| 接收匹配规则 | 低 8 位校验、高 3 位忽略（手册原文） | p11 |

## 二、控制帧 ID 与模式（p13）

| 模式 | 帧 ID | 编码（寄存器 0x0A） |
|---|---|---|
| **MIT** | `CAN ID`（偏移 0x000） | 1 |
| 位置速度 | `CAN ID + 0x100` | 2 |
| 速度 | `CAN ID + 0x200` | 3 |
| 力位混控 | `CAN ID + 0x300` | 4 |

> 本 SDK v1 只实现 MIT。

## 三、MIT 控制帧（8 字节，p12）

| 字节 | 内容 | 代码下标 |
|---|---|---|
| D[0] | `p_des[15:8]` | `frame[0]` |
| D[1] | `p_des[7:0]` | `frame[1]` |
| D[2] | `v_des[11:4]` | `frame[2]` |
| D[3] | `v_des[3:0] \| Kp[11:8]` | `frame[3]` |
| D[4] | `Kp[7:0]` | `frame[4]` |
| D[5] | `Kd[11:4]` | `frame[5]` |
| D[6] | `Kd[3:0] \| t_ff[11:8]` | `frame[6]` |
| D[7] | `t_ff[7:0]` | `frame[7]` |

- 位宽：p 16 位、v/Kp/Kd/t_ff 各 12 位；**高位在前**（大端）。
- 量程：p、v、t_ff 由调试助手设定（`P_MAX/V_MAX/T_MAX`，DM4340 = 12.5 rad / 10 rad/s / 28 N·m）；
  **Kp ∈ [0,500]，Kd ∈ [0,5]**（p13）。

## 四、反馈帧（8 字节，p12）

| 字节 | 内容 |
|---|---|
| D[0] | `ID \| ERR<<4`：低 4 位 = **电机 ID（CAN ID 低 4 位）**，高 4 位 = **状态 ERR** |
| D[1] | `POS[15:8]` |
| D[2] | `POS[7:0]` |
| D[3] | `VEL[11:4]` |
| D[4] | `VEL[3:0] \| T[11:8]` |
| D[5] | `T[7:0]` |
| D[6] | `T_MOS`：驱动 MOS 平均温度，℃ |
| D[7] | `T_Rotor`：线圈平均温度，℃ |

- **帧 ID = Master ID（调试助手设置，默认 0）** —— 不是电机 ID（p12）。
- ERR 状态码（p12）：

| 值 | 含义 | 值 | 含义 |
|---|---|---|---|
| 0 | 失能 | 0xB | MOS 过温 |
| 1 | 使能 | 0xC | 线圈过温 |
| 8 | 超压 | 0xD | 通讯丢失 |
| 9 | 欠压 | 0xE | 过载 |
| 0xA | 过流 | | |

> ⚠️ **推论（约束写进契约）**：ID 只占 4 位 → **同一 Master ID 下最多 16 台（ID 0~15）**。
> 手册 p12 又写"取 CAN_ID 的低 8 位"，与位布局矛盾；按位布局执行，并把这条件当作接口约束。

## 五、特殊帧（8 字节全 0xFF，最后一字节换命令字，p14）

| 命令 | 末字节 | 说明 |
|---|---|---|
| 使能 | `0xFC` | 上电自检后必须使能才能控制 |
| 失能 | `0xFD` | 上电默认状态 |
| 保存位置零点 | `0xFE` | 把当前输出轴位置设为零点，位置给定清零 |
| 清除错误 | `0xFB` | 过温等故障后清错 |

- **帧 ID = 同模式下的控制帧 ID**（MIT → `CAN ID`）（p14「帧ID 如前所述」）。

## 六、参数读写（主机侧用，SDK v1 不实现）

| 操作 | 帧 ID | 载荷 |
|---|---|---|
| 读参数 | `0x7FF` | `CANID_L, CANID_H, 0x33, RID` |
| 写参数 | `0x7FF` | `CANID_L, CANID_H, 0x55, RID, data[4]` |
| 存储参数 | `0x7FF` | `CANID_L, CANID_H, 0xAA, 0x01` |

- 读/写成功的回帧 ID = `MST_ID`，格式与发送相同。
- 存储参数：**只在失能下生效**；耗时最大 30 ms；flash 擦写约 1 万次（p15）。
- 写参数立即生效但不掉电保存；模式切换（寄存器 0x0A）同样掉电丢失（p15）。

## 七、波特率（p15~p16）

| 编码 | 波特率 | 编码 | 波特率 |
|---|---|---|---|
| 0 | 125 K | 5 | **2 M** |
| 1 | 200 K | 6 | **2.5 M** |
| 2 | 250 K | 7 | **3.2 M** |
| 3 | 500 K | 8 | **4 M** |
| 4 | **1 M** | 9 | **5 M** |

改法：写寄存器 `0x23`（值 = 上表编码）；成功后**先以原波特率反馈一帧**，再切新速率。

> ⚠️ **1 Mbps 是分界线**（手册 p16 原文）：
> 「若大于 5 Mbps 则自动默认为 1 Mbps；对于**大于 1 Mbps（不包含 1 Mbps）将自动变成 CAN FD 功能**；
> 若 ≤1 Mbps 自动变成 CAN 2.0B。设置成 CAN FD 的电机仍可接收 CAN 2.0B 数据帧，
> **但发送反馈帧时采用 CAN FD**，因此上层控制器将接收不到反馈数据，并且驱动器会不断报错。」
>
> 结论：**想用 >1 Mbps 就必须让控制器按 CAN FD 接收**（数据段速率、DLC、BRS），
> 这是 port 层的一次接口升级，不是改个数字。FD 模式下反馈帧的 DLC 与载荷是否仍 8 字节 ——
> 手册未写，**待实测**。

## 八、电机自带的掉线保护（p5 / p16）

> 手册 p5 原文：「**通讯丢失防护：设定周期内没有收到 CAN 指令将自动退出"使能模式"**」
> 对应寄存器 `0x09 TIMEOUT`（p16，范围 [0, 2³²−1]，uint32）。

| 项 | 内容 | 出处 |
|---|---|---|
| 行为 | 超过设定周期没收到 CAN 指令 → **自动退出使能**（轴松开） | p5 |
| 配置 | 寄存器 `0x09` TIMEOUT | p16 |
| 故障码 | 触发后 ERR = **0xD 通讯丢失**（反馈帧 D[0] 高 4 位） | p9 / p12 |
| **单位** | **手册未写**（只给了数值范围） | ⚠️ 待实测确认 |

**设计后果（重要）**：
1. 「拔 CAN → 100 ms 内断使能」**电机自身即可实现**，只需把 TIMEOUT 设成 ≤100 ms；
2. 但它与"软件超时保护"是**两条独立防线**，都要留：
   电机侧防"指令断"，软件侧防"反馈断"（能上报、能停机、能拒绝下一次使能）；
3. 配置前必须先确认单位 —— 若单位是 ms，设 100；若是别的刻度，按实测换算。
